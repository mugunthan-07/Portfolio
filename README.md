# Mugunthan — Developer Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For a local development server, use VS Code Live Server.

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your real email.
2. Replace `YOUR-LINKEDIN` and `YOUR-GITHUB` with your profile usernames/URLs.
3. Add your actual resume PDF and add a resume link if you want a resume button.
4. Verify every skill and project detail is accurate before sharing with recruiters.

## Files
- `index.html` — page content
- `style.css` — responsive layout and visual design
- `script.js` — mobile menu and current year

No framework or build step is required.
